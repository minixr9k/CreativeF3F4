# F3+F4 Creative

Небольшой плагин для Bukkit/Spigot/Paper серверов, который позволяет игрокам использовать стандартное меню быстрой смены режима игры (**F3 + F4**) при наличии пермишна `minecraft.command.gamemode`

## 📌 Описание

По умолчанию в Minecraft комбинация клавиш **F3 + F4** и само меню выбора режима игры жестко завязаны на уровень оператора сервера (OP). Данный плагин перехватывает необходимые пакеты с помощью **PacketEvents**, проверяет наличие нужного права у игрока и открывает меню без выдачи полного оператора

## 🔑 Права

* `minecraft.command.gamemode` — разрешает использование меню смены режима игры через комбинацию **F3 + F4**.

## ⚙️ Зависимости

Для работы плагина на сервере обязательно должна быть установлена библиотека:
* **[PacketEvents](https://github.com/retrooper/packetevents)**
